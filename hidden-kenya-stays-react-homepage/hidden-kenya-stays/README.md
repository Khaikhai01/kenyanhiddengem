# Hidden Kenya Stays — React Homepage

This is the first frontend step for the Hidden Kenya Stays concept.

## Run it

1. Install Node.js (LTS).
2. Open this folder in your terminal.
3. Run:
   npm install
   npm run dev
4. Open the local URL Vite prints (usually http://localhost:5173).

## What to learn first

Start in `src/main.jsx`:
- `destinations` = destination cards
- `stays` = accommodation cards
- `benefits` = feature/value cards
- `App()` = page structure

Then open `src/styles.css` to experiment with layout, spacing, colors and responsive behavior.

The homepage currently uses remote Unsplash images for the accommodation/destination cards so you can focus on learning React first. The generated design reference is also included as `src/hero-reference.png`.
